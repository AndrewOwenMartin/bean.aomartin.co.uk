# Context-free and context-sensitive SDS

## The winner-takes-all problem

Standard SDS converges hard. Once a cluster forms at a high-scoring hypothesis, it tends
to grow until it dominates the swarm — most agents pile onto the best answer found so far,
and exploration slows to a trickle.

For many tasks, that's exactly what you want. But consider what happens when the search
space contains two equally good answers. Standard SDS will converge on one of them. The
other starves. The cluster at the "winner" can be orders of magnitude larger than any
activity at the second answer. Eventually the two might trade dominance back and forth,
but at any given moment the swarm is committed to one hypothesis and barely looking at
anything else.

There are three situations where this is a problem:

1. **Multiple optimal hypotheses** — there are several equally good answers and you want
   to find all of them, not just one.
2. **Top-k search** — you want the best hypothesis *and* the next-best ones ranked
   below it.
3. **Dynamic search spaces** — the search space is changing over time, so the optimal
   answer now may not be optimal later. Standard SDS tracks a moving optimum eventually,
   but a large cluster is slow to abandon: agents only leave through test failures. In
   context-free SDS, active agents also leave through collisions — the larger the old
   cluster, the faster it erodes. A new optimum therefore has more free agents available
   to discover it *and* active pressure clearing the old cluster at the same time.

In all three cases, you need the swarm to keep exploring even after it has found something
good. The two variants here do this by adding a cost to being active: an active agent can
now be knocked back to inactive during the diffusion phase.

## Context-free diffusion

In standard SDS, only inactive agents act during diffusion. Active agents sit on their
hypothesis and wait for the next test. Context-free diffusion changes this: every agent
polls a random agent, active or not.

The new rule: if an active agent polls another active agent, it calls DH() and randomises
its hypothesis — the same thing an inactive agent does when it finds nobody to recruit
from. In both cases, the polling agent starts fresh.

```
DCONTEXT-FREE(agent, swarm):
  polled ← random agent in swarm

  if agent is inactive and polled is active:
    hypothesis of agent ← hypothesis of polled

  else if agent is active and polled is active:
    hypothesis of agent ← DH()

  else if agent is inactive:
    hypothesis of agent ← DH()
```

The effect on the swarm: as a cluster grows, collisions between active agents become more
frequent. Each collision sends the polling agent back to DH() — into the same exploring
pool as inactive agents who found nobody to recruit from. This is a form of negative
pressure: the larger the cluster, the faster it loses members to collisions. The cluster
stabilises where the collision attrition balances against recruitment from the inactive pool.
Unlike standard SDS, where clusters only shrink through test failures, context-free SDS
has a second attrition mechanism that scales directly with cluster size.

## Context-sensitive diffusion

Context-free diffusion has a side-effect: clusters at different hypotheses interfere with
each other. An active agent at hypothesis A can collide with an active agent at hypothesis B
and get knocked out, even though the two clusters have nothing to do with each other.
The bumping is indiscriminate.

Context-sensitive diffusion adds one condition: an active agent is only knocked inactive
if it collides with another active agent *at the same hypothesis*.

```
DCONTEXT-SENSITIVE(agent, swarm):
  polled ← random agent in swarm

  if agent is inactive and polled is active:
    hypothesis of agent ← hypothesis of polled

  else if agent is active and polled is active and same hypothesis:
    hypothesis of agent ← DH()

  else if agent is inactive:
    hypothesis of agent ← DH()
```

The effect: the cap is per cluster rather than global. Within each cluster, collisions
still prevent runaway growth. But a cluster at hypothesis A doesn't interfere with a cluster
at hypothesis B. Multiple clusters can form and coexist stably — each capped at a moderate
size, none able to dominate the swarm entirely.

## Two equal peaks

The clearest way to see the difference between these variants is to put the swarm in front
of two hypotheses with identical scores.

**Standard SDS** does not split evenly. Two perfectly equal clusters are an unstable
equilibrium: any small fluctuation tips the balance, triggering a positive feedback loop
where the slightly larger cluster recruits faster and grows further. One cluster quickly
dominates.

**Context-free SDS** has the same instability. The global collision cap limits how many
agents are active in total, but it does not change the underlying recruitment dynamic —
the larger cluster is still polled more often by inactive agents. One cluster still dominates,
just at a smaller overall size.

**Context-sensitive SDS** breaks the instability. Because clusters at different hypotheses
never collide, each one's attrition is self-contained — cluster A only competes with
itself. If both hypotheses score equally, both clusters independently reach the same
equilibrium size and neither can crowd out the other. Two stable clusters coexist.

## What each variant caps

|                       | What is capped                               |
| --------------------- | -------------------------------------------- |
| Standard SDS          | Nothing — the dominant cluster grows freely  |
| Context-free SDS      | Total active agents (global cap)             |
| Context-sensitive SDS | Active agents per cluster (per-cluster cap)  |

Context-sensitive allows stable clusters to form, stoppinttttt single cluster from monopolising
the swarm.

## Robustness

*Robustness* (ζ) is a measure of how noisy a search space can be and still allow SDS to
form a stable cluster. A higher value means the algorithm can find and hold answers under
noisier conditions.

| Variant               | Robustness (ζ) |
| --------------------- | -------------- |
| Standard SDS          | ≈ 0.614        |
| Context-sensitive SDS | ≈ 0.614        |
| Context-free SDS      | ≈ 0.307        |

Context-sensitive SDS matches the robustness of standard SDS — adding the per-cluster
cap costs nothing in terms of noise tolerance. Context-free SDS has lower robustness: the
global cap keeps clusters smaller, and smaller clusters need a stronger signal to hold
together.

## Connection to halting

One of the challenges in halting SDS is detecting that a stable cluster has formed. Standard
SDS keeps growing past the point of detection, so any threshold-based halting method
risks either halting too early (before a good cluster forms) or too late (after unnecessary
searching).

Context-free SDS has a natural advantage here. Because the global cap limits cluster size,
the stable cluster size is determined by the algorithm parameters rather than continuing
to grow indefinitely. The swarm reaches a predictable equilibrium, which makes it easier
to detect that a cluster has formed — and to trust that it won't keep changing once
detected. This comes at the cost of a higher minimum convergence threshold: context-free
SDS needs a stronger signal to form any cluster at all.
