# Context-free and context-sensitive SDS

## The winner-takes-all problem

Standard SDS has been criticised for its behaviour of forming a single large cluster, leaving few agents to test hypotheses in the remainder of the search space and potentially missing superior solutions.
Two variants have been defined which decrease the number of active agents and hence to increase the number of agents generating new hypotheses.
These variants add the possibility of active agents generating new hypotheses during the diffusion phase.
The variants are named context-free diffusion and context-sensitive diffusion.

**Context-free diffusion** introduces a mechanism where active agents poll an agent at random from the swarm and in the case that the polled agent is active, the polling agent will generate a new hypothesis using `DH`.

**Context-sensitive diffusion** introduces a similar mechanism but adds an extra condition. Active agents poll an agent at random from the swarm but the polling agent will only generate a new hypothesis using `DH` if the polled agent is active _and_ both agents share the same hypothesis.

## Context-free diffusion

In standard SDS, only inactive agents act during diffusion. Active agents maintain their hypothesis. Context-free diffusion changes this: every agent polls a random agent, active or not.

The new rule: if an active agent polls another active agent, it calls DH() and randomises its hypothesis.

```
D-CONTEXT-FREE(agent, swarm):
  polled ← random agent in swarm

  if agent is inactive or polled is active:
    if agent is inactive and polled is active:
      hypothesis of agent ← hypothesis of polled
    else
      hypothesis of agent ← DH()
```

The effect on the swarm: as a cluster grows, collisions between active agents become more
frequent. Each collision sends the polling agent back to DH() — into the same exploring
pool as inactive agents who found nobody to recruit from. This is a form of negative
pressure: the larger the cluster, the faster it loses members to collisions. The cluster
stabilises where the collision attrition balances against recruitment from the inactive pool.
Unlike standard SDS, where clusters only shrink through test failures, context-free SDS
has a second attrition mechanism that scales directly with cluster size.

## Context-sensitive diffusion

Context-free diffusion has a side-effect: clusters at different hypotheses interfere with
each other. An active agent at hypothesis A can collide with an active agent at hypothesis B
and get knocked out, even though the two clusters have nothing to do with each other.

Context-sensitive diffusion adds one condition: an active agent is only knocked inactive
if it collides with another active agent *maintaining the same hypothesis*.

```
DCONTEXT-SENSITIVE(agent, swarm):
  polled ← random agent in swarm

  if agent is inactive and polled is active:
    hypothesis of agent ← hypothesis of polled
  else
    a ← agent is inactive
    b ← polled is active and hypothesis of agent = hypothesis of polled
    if a or b:
      hypothesis of agent ← DH()
```

The effect: the cap is per cluster rather than global. Within each cluster, collisions
still prevent runaway growth. But a cluster at hypothesis A doesn't interfere with a cluster
at hypothesis B. Multiple clusters can form and coexist stably — each capped at a moderate
size, none able to dominate the swarm entirely.

## Two equal peaks

The clearest way to see the difference between these variants is to consider a swarm in a search space with two hypotheses with identical scores.

**Standard SDS** does not split evenly. Two perfectly equal clusters are an unstable
equilibrium: any small fluctuation tips the balance, triggering a positive feedback loop
where the slightly larger cluster recruits faster and grows further. One cluster quickly
dominates.

**Context-free SDS** has the same instability. The global collision cap limits how many
agents are active in total, but it does not change the underlying recruitment dynamic —
the larger cluster is still polled more often by inactive agents. One cluster still dominates,
just at a smaller overall size.

**Context-sensitive SDS** breaks the instability. Because clusters at different hypotheses
never collide, each one's attrition is self-contained — cluster A only competes with
itself. If both hypotheses score equally, both clusters independently reach the same
equilibrium size and neither can crowd out the other. Two stable clusters coexist.

## What each variant caps

|                       | What is capped                               |
| --------------------- | -------------------------------------------- |
| Standard SDS          | Nothing — the dominant cluster grows freely  |
| Context-free SDS      | Total active agents (global cap)             |
| Context-sensitive SDS | Active agents per cluster (per-cluster cap)  |

Context-sensitive allows stable clusters to form, stopping any single cluster from monopolising the swarm.

## Robustness

*Robustness* (ζ) is a measure of how noisy a search space can be and still allow SDS to
form a stable cluster. A higher value means the algorithm can find and hold answers under
noisier conditions.

| Variant               | Robustness (ζ) |
| --------------------- | -------------- |
| Standard SDS          | ≈ 0.614        |
| Context-sensitive SDS | ≈ 0.614        |
| Context-free SDS      | ≈ 0.307        |

Context-sensitive SDS matches the robustness of standard SDS — adding the per-cluster
cap costs nothing in terms of noise tolerance. Context-free SDS has lower robustness: the
global cap keeps clusters smaller, and smaller clusters need a stronger signal to hold
together.
